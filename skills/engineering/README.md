# Engineering

Daily code work. Promoted — listed in the plugin and `/fancy-discover`.

## User-invoked

- **[fancy-discover](./fancy-discover/SKILL.md)** — Discover the skills in this collection and which one to reach for.
- **[fancy-init](./fancy-init/SKILL.md)** — Initialize this workspace with Fancy's conventions — issue tracker, domain docs, and Cursor rules.
- **[fancy-locale](./fancy-locale/SKILL.md)** — Switch installed skill bodies between English (default) and Simplified Chinese.

## Model-invoked

- **[fancy-flow](./fancy-flow/SKILL.md)** — Start or continue a product / vibe-coding pipeline. Intent-triggered; not for regex or a one-file bugfix.
- **[fancy-orient](./fancy-orient/SKILL.md)** — Research complaints first, then lock who / how painful / why now, and write proposal.md. No git repo.
- **[fancy-shape](./fancy-shape/SKILL.md)** — Init, three visual directions then high-fidelity prototype as contract, then decisions.md and tasks.md. No business code.
- **[fancy-build](./fancy-build/SKILL.md)** — Write business code one task at a time from tasks.md.
- **[fancy-harden](./fancy-harden/SKILL.md)** — Physical tests and drift alignment. Evidence, not claims.
- **[fancy-ship](./fancy-ship/SKILL.md)** — Release and update memory.

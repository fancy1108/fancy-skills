# Fancy Flow

按意图接手的编排器。判断当前阶段，只跑下一条**已发布**的技能，在卡点停下。若你是因为正则、traceback 或改一个文件被唤起的，**拒绝流水线**，直接回答问题。

用户说要**做一个东西**（应用、工具、产品）就是开新产品。这就是本技能。不是查正则。

## 不要抢走日常问答

用户只是查正则、看报错、改一个文件，或任何不是「新产品 / vibe coding / 继续这个产品」的事，离开。不要提 `proposal.md`。

## 阶段

| 阶段 | 人类步骤 | 出门卡点（离开前必须有） |
| --- | --- | --- |
| `/fancy-orient` | 1 调研痛点，2 写提案 | `proposal.md` **已被接受** + 三问稳定。先调研再问三问。不建 git 仓库 |
| `/fancy-shape` | 3 初始化，4 视觉，5 或 5.5 契约，6 拆任务 | `design.md` + **已接受的**高保真原型 + **已接受的** `tasks.md` + `decisions.md` |
| `/fancy-build` | 7 写代码 | 按任务交付的真代码，一次一条 |
| `/fancy-harden` | 8 测试，8.5 真相对齐 | 物理验证日志 + 纠偏。证据，不是口头 |
| `/fancy-ship` | 9 发布 | 上线（或已交付）状态 + 已更新 memory |

**三问**（用户答，Agent 不得编造）：给谁用？有多痛？为什么现在做？

**高保真原型**是 **shape** 的交付物，不是可选项。后面阶段不得违背这份交互契约。三条分支见 `/fancy-shape`（从零做 demo、已有原型、无 UI）。

## 检测并分派

看工作区。只跑**下一个**阶段。该阶段碰到**人确认锁**，就停这一轮，等回复。不要在同一条消息里开下一阶段。

磁盘上的文件是**草稿**。不等于用户同意。

| 你看到什么 | 做什么 |
| --- | --- |
| 没有提案，或写好的提案还没被接受 | `/fancy-orient`（即使已经起了名字或丢进来一个 UI 目录） |
| 提案已接受，shape 门未绿 | `/fancy-shape` — 只有他们接受了提案（或对已接受的提案说继续）才开 |
| shape 门已绿 **且** 他们接受了 `tasks.md`，任务还开着 | `/fancy-build` |
| 任务做完，他们说继续，没有物理验证 / 漂移还开着 | `/fancy-harden` |
| 已硬化，他们用过了，未发布 | `/fancy-ship` — 先亮发布计划，等人说可以 |
| 用户想跳去写代码 | 拒绝，直到 **shape 门**绿（在那之前先 orient） |
| 小 bug / 改一个文件，且他们**没有**说继续做这个产品 | 拒绝流水线。不要开 orient |

## 人确认锁（不许跳）

停下。问一句。等回复。然后改，或往下走。

| 草稿 | 问 | 等到他们 |
| --- | --- | --- |
| 调研表 | 哪条是你的痛？我哪里搞错了？ | 有反应 |
| `proposal.md` | Pitch / MVP / 不做清单对吗？ | 接受，或指出要改的段 |
| 初始化菜单 | 哪个档次 / 栈 / 持久化 | 选一个 |
| 三个视觉方向 | 选哪个（或混） | 选 |
| 原型 / demo | 打开它。要改什么？ | 接受，或给修改清单 — 改完再问一遍 |
| `tasks.md` | 这样拆对吗？ | 接受 |
| 硬化证据 | 你自己用一次。哪里不对？ | 他们用过了 |
| 发布计划 | 上线 / 仅本地 — 可以吗？ | 可以 |

禁止：写完 `proposal.md` 立刻跑 `/fancy-shape`。禁止：写完 `demo.html` 立刻写 `contract.ts`。禁止：同一轮里宣布 shape 完成并开始 `/fancy-build`。

永远不要调用仅用户触发的技能（`/fancy-discover`、`/fancy-init`、`/fancy-locale`）。建仓是 shape 自己的事。

本对话里已经点名要做什么，把那句话当作种子传给 `/fancy-orient`。不要让 orient 再问想做什么。

笔记里点名的辅助技能若本集合没有，**在当前阶段内部做完**。不要假装有一条不存在的技能。

## 硬卡点

- 三问稳定、**提案已被接受**之前 **禁止 `git init`**。orient 不建仓。flow 不建仓。shape 才建仓。
- **shape 门**绿之前禁止写业务代码，包括用户**已接受**的高保真原型（或 `decisions.md` 里明确的无 UI 豁免）。

# Issue tracker (GitLab)

Issues for this repo live in **GitLab Issues** on the repo's GitLab remote. Use the [`glab`](https://gitlab.com/gitlab-org/cli) CLI (`glab issue list`, `glab issue create`, `glab issue update`, `glab issue note`).

PRs/MRs as a request surface: **off**. Do not pull external merge requests into any triage queue unless this flag is later set to on.

When creating an issue from an engineering skill, include enough context that a later session can execute it without the originating chat.

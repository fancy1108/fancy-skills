# Hunt queries (step 1)

Search for what is broken. Prefer recent posts (last 1–2 years). Keep the domain of the seed if they gave one.

## Pain

- "I hate that [category] …"
- "why isn't there a tool that does A and B"
- "how do I [job] without [bloated app]"
- site:reddit.com [category] "uninstalled" OR "too complicated" OR "just want"

## Gap

- [competitor] 1 star review
- [competitor] "feature request" ignored / years
- [category] "too many features" OR "just want to log"

## Edge

- [new API or model] [old job]
- "I built a weekend [category] widget"

## Seed example

Seed = 减肥桌面小工具 → search weight-tracker / MyFitnessPal / Lose It / 体重记录 抱怨 / desktop widget — **not** "developers hate that there is no tool".

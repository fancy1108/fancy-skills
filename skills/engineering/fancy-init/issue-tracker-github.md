# Issue tracker (GitHub)

Issues for this repo live in **GitHub Issues** on the repo's GitHub remote. Use the `gh` CLI (`gh issue list`, `gh issue create`, `gh issue edit`, `gh issue comment`).

PRs as a request surface: **off**. Do not pull external pull requests into any triage queue unless this flag is later set to on.

When creating an issue from an engineering skill, include enough context that a later session can execute it without the originating chat.

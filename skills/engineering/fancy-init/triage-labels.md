# Triage labels

Canonical roles map to these label strings in the issue tracker. Use the strings, not synonyms.

| Role | Label |
| --- | --- |
| Needs triage | `needs-triage` |
| Needs info | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Won't fix | `wontfix` |

An issue carries one of these roles at a time.

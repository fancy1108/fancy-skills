# Domain docs

Layout: **single-context**.

- Glossary and ubiquitous language: `CONTEXT.md` at the repo root.
- Architecture Decision Records: `docs/adr/`.

## Consumer rules

- Prefer terms from `CONTEXT.md` in code, commits, issues, and agent prose. If a term is listed under **Avoid**, do not use it.
- Before reversing a recorded decision, read the ADRs in `docs/adr/` that touch the area.
- If the glossary is missing a term that keeps recurring, add it — don't keep paraphrasing around the gap.

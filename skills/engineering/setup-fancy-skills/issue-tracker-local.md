# Issue tracker (local markdown)

Issues for this repo live as markdown files under `.scratch/` in this repository. There is no remote tracker.

Suggested layout (create folders as needed):

```
.scratch/
  issues/
    <slug>.md
```

Each issue file should have a title heading, a short status line, and enough context that a later session can execute it without the originating chat.

Do not call `gh` or `glab` for this repo's issues.
